Amenza Spooting (Suplantacoin)
  Riesgo:
          * Suplantación de IP para evadir bloqueos
  Mitigacion
          * Validar las cabeceras del API Gatway para aceptar solo trafico de este
Tampering (Manipulacion)
  Riesgo: 
          * Inyeccion de SQL al manipular el parametro {id} para alterar la consulta
  Mitigacion:
          * Uso de consulta parametizable
          * Validar el tipo de datos de {id} en el API Gataway

  Repudation (Repudio)
    Riesgo:
          * Escaneo del catalogo y luego negar haberlo echo porque el sistema no guarda registro de la IP de la actividad
    Mitigacion:
          * Centralizar Logs de Accedo en el API Gataway
          * No loguear datos sensible

  Information Disclosure (Divulgacion)
    Riesgo:
          * Consultar un Id de un producto que no debería ser publico
          * El resultado de la respuesta regresa todos los datos
    Mitigacion:
          * Incluir en la consulta algun estado valido del producto para regresar la informacion
          * Regresar en la consulta solo los datos que deban ser publicos

    Denial of Service
      Riesgo:
          * Como la URL es publica puede ser susceptible a ataques masivos o el envio de id muy largos que saturen el                    servidor 
      Mitigacion:
          * Limitar el tamaño del Payload de entrada

    Elevation of Provilage
      Riesgo: 
          * Cualquiera puede realizar consulta del {id} y puede usar un payload malicioso
      Mitigacion:
          * Mantener un esquema de autirazion
